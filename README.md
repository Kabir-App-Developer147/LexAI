# LexAI
A local, private AI assistant for small businesses and professionals in India.
Runs entirely on your machine. No cloud. No subscription. No data leaves your device.

## What it does
- Chat with an AI assistant with memory
- Ask questions about your own documents (PDF, DOCX, TXT)
- Powered by Ollama + Gemma3

## Setup
1. Install Ollama and pull gemma3:4b and nomic-embed-text
2. pip install -r requirements.txt
3. Put documents in the /data folder
4. python core/rag.py

## Why
Most AI tools are expensive and cloud-based. 
A small doctor, CA, or business owner in India shouldn't need a subscription to use AI on their own files.
